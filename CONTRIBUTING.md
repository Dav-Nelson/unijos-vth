# Contributing to Unijos VTH

We appreciate your interest in making veterinary clinic management more accessible.

## Workflow
- **Branching**: Use descriptive branch names (e.g., `feat/billing`, `fix/login`).
- **Commits**: Follow conventional commit messages (`feat:`, `fix:`, `docs:`, `chore:`).
- **Security**: Never commit files containing secrets (e.g., `.env.local`). Always use environment variables.
- **Verification**: Run `npm run lint` and `npx tsc --noEmit` before submitting a Pull Request.

## Security
For security issues or concerns, please contact the maintainer directly through your GitHub profile or create a sensitive issue.
